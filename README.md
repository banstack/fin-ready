# FinReady

FinReady (or Finacial Ready) is a personal finance tool used to provide users with an inference in their personal finance decision making process.

## Features

### (1) Security Viewer:
Users can visit individual security pages to view health and score metrics

### (2) Top Peformers
This view allows users to see top performing individual securities as well as indexes

## Disclaimer

FinReady is a hobby-project meaning that its intention is not to be used as a legitmate source to determine your investing decisions. Instead you can use FinReady to help formulate your decisions but at no point does FinReady make these decisions for you.
